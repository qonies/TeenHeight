# 子女身高预测（TeenHeight）

综合父母与亲属身高、结合儿童生长标准（WHO / 中国），在浏览器本地预测子女成年身高的网页工具。纯本地计算，**不上传、不存储任何个人数据**。

> **免责声明：本工具仅供家庭参考，不构成医学建议。** 孩子的最终身高受营养、睡眠、运动、疾病等多种因素影响，预测结果存在个体差异。

## 功能特性

- **三级精度档位**：仅父母（基础 ±8.5cm）→ 父母 + 孩子当前信息（进阶 ±5cm）→ 再加亲属数据（增强 ±4cm）
- **三种预测方法**：父母平均身高法（MPH）基线；有孩子当前身高/月龄时用 CMH 近似校正；4–17.5 岁且有体重时自动选用 Khamis-Roche 法
- **家族亲属加权修正（实验性，±4cm 上限）**：四位祖辈 + 旁系亲属（叔伯/姑/姨/舅，可多条），亲缘系数加权（父母 0.5，祖辈/旁系各 0.25），重复关系自动取均值并提示
- **双生长标准可切换**：WHO（0–228 月，官方逐月 LMS）与中国城市儿童参考（Zong & Li 2013，0–216 月，离散节点线性插值）
- **预测值与标准解耦**：成年身高预测值为绝对值（cm），不随参照标准切换而改变；切换标准仅影响 SDS、百分位与生长曲线
- **可视化输出**：SVG 百分位曲线图（P3–P97）、逐年预测表、预测依据说明
- **导出**：结果卡片一键导出 JPG / PDF
- **输入校验**：越界/格式/精度即时提示，提供示例数据与一键清空

## 预测方法

| 方法 | 说明 | 适用条件 |
|---|---|---|
| MPH | `(父高 + 母高 ± 13) / 2`（男 +13 / 女 −13） | 仅需父母身高 |
| CMH | `MPH + K × 孩子当前身高 SDS`（K = 2.0，可标定） | 有月龄 + 当前身高 |
| Khamis-Roche | 基于孩子身高/体重/父母身高的回归系数表（内部换算英寸/磅） | 月龄 48–210 且有体重 |

- 家族修正：各亲属按自身性别相对成人参照标准化后加权平均，与父母均值比较，乘增益（0.5）并截断至 ±4cm。**实验性**，参数未经大规模数据标定。
- CMH 的 `K` 与家族修正的增益/上限均为**可标定参数**，当前取值以保证行为合理与可解释为准。

## 参照数据

| 标准 | 覆盖范围 | 来源 |
|---|---|---|
| WHO | 0–228 月 | WHO Child Growth Standards（0–5 岁）+ WHO 2007 Growth Reference（5–19 岁） |
| 中国 | 0–216 月 | 中国城市儿童生长参考（Zong & Li 2013, PLOS ONE），取自公开 R 包 childsds |

LMS 数据由脚本生成（`src/data/`，勿手改）；如需重新生成：

```bash
npm run generate:data   # 需联网，从 WHO anthro/anthroplus 与 childsds 仓库下载
```

## 隐私

- 所有计算在浏览器本地完成，无账号、无网络请求、无 Cookie/本地存储
- 关闭页面即清空全部输入

## 技术栈

- Vite 7 + TypeScript 5.9（strict），无框架（原生 DOM），单页应用
- 测试：Vitest 3（core 用 node 环境，UI 用 jsdom），用例编号见 `测试用例文档.md`
- 运行时依赖仅两个：`html-to-image`（JPG 截图）、`jspdf`（PDF 导出）

## 项目结构

```
src/core/    预测引擎（predict 编排 + mph/cmh/khamis-roche/family/lms/growth/validate）
src/data/    WHO/中国 LMS 数据与 KR 系数（脚本自动生成）
src/ui/      界面（app/chart/export/main + styles.css）
scripts/     数据生成脚本
tests/       9 个测试文件（111 用例）
```

架构分层严格单向依赖：`ui → core → data`，UI 无业务逻辑，core 无 DOM 依赖。
