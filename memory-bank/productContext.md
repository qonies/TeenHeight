# 产品上下文（Product Context）

## 为什么做这个项目
家长普遍关心孩子成年身高，现有工具多只用父母身高套简单公式，未利用祖辈/旁系亲属信息，也未结合孩子当前生长情况。本项目提供更个体化、可解释的预测。

## 目标用户与场景
| 项目 | 内容 |
|---|---|
| 主要用户 | 关注孩子成年身高的家长 |
| 场景 | 家庭自测、体检后参考、运动/营养规划参考 |
| 环境 | 桌面/手机浏览器，单次会话，低频复测 |
| 前置知识 | 无需医学背景，界面全中文通俗表述 |

## 用户体验目标
- 必填区默认展开（性别 + 父母身高），选填区默认折叠并标注"填写可提升精度"。
- 实时校验、越界即时提示、不阻塞其它输入；提供"填入示例"与"一键清空"。
- 结果页：预测值 + 区间 + 精度档位徽章 + 参照标准徽章 → 曲线图 → 逐年表 → 预测依据 → 免责声明。
- 可访问性：键盘可操作、SVG 图表有 aria-label、颜色对比达标。

## 隐私承诺（必须始终遵守）
- 所有计算在浏览器本地完成，不上传、不存储个人数据。
- 关闭页面即清空；不使用 Cookie/本地存储保存身高数据；不接第三方分析/广告。
- 备注为自由文本，仅本地展示于结果卡（innerHTML 前必须转义，见 app.ts escapeHtml）。

## 结果解释原则
- 每次预测输出 explanation 数组：基础方法、精度档位、孩子当前百分位、亲属修正量（含重复关系均值提示）、参照标准、免责声明。
- 亲属修正与 CMH 系数为可标定参数，界面与文档均标注"实验性/近似"。
